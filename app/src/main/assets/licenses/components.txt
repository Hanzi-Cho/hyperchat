Third-party notices for the Android app

The dependencies directory contains license files supplied by Android libraries,
including LiteRT-LM, ML Kit and Google Play services. Each directory identifies
the original artifact and version. Paired third_party_licenses.json and .txt
files are kept together so the byte offsets in the index remain valid.
